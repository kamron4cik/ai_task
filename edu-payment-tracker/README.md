# EduPay — Мини-учёт оплат учебного центра

Система для отслеживания оплат учеников: управление учениками, фиксация платежей и просмотр должников за любой месяц.

## Стек технологий

- **Backend**: Node.js + Express
- **БД**: SQLite (через `better-sqlite3` — синхронный, нет лишних зависимостей)
- **Frontend**: Vanilla HTML / CSS / JS — адаптивный тёмный дизайн

---

## Часть 1. Запуск с нуля

### Требования

- Node.js ≥ 18
- npm ≥ 9

### Установка и запуск

```bash
# 1. Перейти в папку проекта
cd edu-payment-tracker

# 2. Установить зависимости
npm install

# 3. Запустить сервер
npm start
```

Сервер запустится на **http://localhost:3000**. База данных `payments.db` создаётся автоматически при первом запуске.

## API-эндпоинты

### Ученики

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/students` | Список всех учеников |
| `POST` | `/students` | Создать ученика |
| `PUT` | `/students/:id` | Изменить ученика |
| `DELETE` | `/students/:id` | Удалить ученика (+ все платежи) |

**Тело запроса (POST/PUT):**
```json
{
  "name": "Иван Иванов",
  "phone": "+7 999 123-45-67",
  "group_name": "A-101",
  "monthly_amount": 5000
}
```

### Оплаты

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/payments` | Добавить оплату |
| `GET` | `/payments?student_id=1` | Список оплат ученика |

**Тело запроса (POST):**
```json
{
  "student_id": 1,
  "amount": 3000,
  "date": "2026-10-15"
}
```

### Должники

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/debtors?month=YYYY-MM` | Ученики, недоплатившие за месяц |

**Пример ответа:**
```json
[
  {
    "id": 1,
    "name": "Иван Иванов",
    "phone": "+7 999 123-45-67",
    "group_name": "A-101",
    "monthly_amount": 5000,
    "paid": 2000,
    "debt": 3000
  }
]
```

## Часть 2. Что бы я улучшил за неделю

1. **Аутентификация и роли** — добавить JWT-авторизацию, роли «администратор» и «кассир». Сейчас API полностью открытое, что неприемлемо для продакшна.

2. **Уведомления о должниках** — настроить cron-задачу (node-cron), которая в начале каждого месяца автоматически рассылает SMS/Telegram-сообщения должникам через соответствующее API.

3. **Миграции БД** — заменить прямое `db.exec()` на систему миграций (например, `db-migrate` или `Knex.js`), чтобы безопасно эволюционировать схему БД на проде без потери данных.

4. **Тесты** — написать интеграционные тесты на Jest + supertest для всех эндпоинтов, особенно для логики подсчёта должников с граничными случаями (частичная оплата, нулевая оплата, переплата).

5. **Docker + docker-compose** — упаковать в контейнер, чтобы запуск `docker compose up` было достаточно для развёртывания в любой среде без ручной установки Node.js.
