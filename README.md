# ai_task — Тестовое задание, Ecomdev

Мини-система учёта оплат учебного центра.  
Стек: **Node.js · Express · SQLite · Vanilla JS**

---

## Структура репозитория

```

├── edu-payment-tracker/   ← исходный код проекта
│   ├── server.js          ← точка входа Express-сервера
│   ├── db.js              ← инициализация SQLite БД
│   ├── routes/
│   │   ├── students.js    ← CRUD учеников
│   │   ├── payments.js    ← добавление и список оплат
│   │   └── debtors.js     ← должники за месяц
│   ├── public/
│   │   ├── index.html     ← веб-интерфейс
│   │   ├── style.css      ← тёмная тема, адаптив
│   │   └── app.js         ← frontend логика
│   ├── package.json
│   └── README.md          ← подробная документация проекта
└── README.md              ← этот файл
```

---

## Быстрый старт

```bash
cd edu-payment-tracker
npm install
npm start
# → http://localhost:3000
```

> Требуется **Node.js ≥ 18**. База данных `payments.db` создаётся автоматически.

## Что реализовано

### Часть 1 — REST API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/students` | Список всех учеников |
| `POST` | `/students` | Создать ученика |
| `PUT` | `/students/:id` | Изменить ученика |
| `DELETE` | `/students/:id` | Удалить ученика |
| `POST` | `/payments` | Добавить оплату |
| `GET` | `/payments?student_id=X` | Оплаты ученика |
| `GET` | `/debtors?month=YYYY-MM` | Должники за месяц |

### Часть 2 — Веб-интерфейс (Вариант Б)

- 🔴 **Должники** — список с прогресс-баром, суммой долга, фильтр по месяцу
- 👥 **Ученики** — создание, редактирование, удаление, история оплат
- 💳 **Оплата** — форма внесения платежа
- Тёмная тема, glassmorphism, адаптив для мобильных

Подробная документация с командами запуска и 5 пунктами улучшений — в [`edu-payment-tracker/README.md`](./edu-payment-tracker/README.md).

## Часть 4 — Использование ИИ

**Инструменты**: Antigravity IDE (Claude Sonnet). Лучший результат дали точные промпты с полным контекстом — схема БД, список эндпоинтов и требования к UI передавались за один запрос, что исключило итерации.

**Где ошибся**: ИИ сгенерировал `app.get('*', ...)` — синтаксис Express 4, который не работает в Express 5 (`PathError: Missing parameter name`). Ошибка была поймана сразу при первом запуске и исправлена на `'/{*path}'`.

**Что писал сам**: SQL-запрос для должников (LEFT JOIN + LIKE по дате + HAVING), структуру файлов проекта, разбивку по роутам. ИИ генерировал шаблонный CRUD-код и CSS дизайн-систему.
